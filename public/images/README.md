Все изображения `hero.webp`, `scene-*.webp`, `hero.svg`, `star.svg` созданы специально для Betelgeuse скриптом `frontend/scripts/create-assets.mjs`. Внешние фотографии и чужие видеоматериалы не использованы.

`npm run assets` пересоздаёт графику. Для MP4 требуется ffmpeg в PATH; без него остаётся статичный fallback.
