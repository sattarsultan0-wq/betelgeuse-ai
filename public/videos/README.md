`hero.mp4` — собственный процедурный монохромный видеолуп, созданный из оригинальной SVG-композиции. Не является результатом AI-генерации.

Заменить своим лицензированным бесшовным MP4 (H.264, без аудио, желательно до 5 МБ). Путь `/videos/hero.mp4`. Poster — `/images/hero.webp`.

Исходные видео галереи лежат здесь. Совместимые версии H.264 (без звука, yuv420p, faststart) — в `optimized/`. Поля `sourceVideo`, `video`, `poster` находятся в `src/assets/showcase.js`, Hero — в `src/assets/media.js`. После замены исходника запускай `npm run videos:prepare` (нужен FFmpeg в PATH). Исходники не перезаписываются; настоящие картинки первого кадра сохраняются в `public/images/video-posters/`.

Не указывай MP4 как poster. На мобильном одновременно играют до двух видимых превью, другие карточки показывают poster. По нажатию открывается видео с controls. Если система запрещает autoplay, можно запустить его касанием. Произвольные исходные AV1 MP4 могут не воспроизводиться на iPhone — используй подготовленную H.264-копию.
