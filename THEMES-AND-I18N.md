# Темы и языки Betelgeuse

В настройках боковой панели Workspace добавлен раздел «Внешний вид»: тёмная/светлая тема и выбор языка. В Header главной страницы доступно меню RU / EN / KK. Меню поддерживает клавиатуру, Escape, закрытие при выборе, клике снаружи и уходе фокуса.

## Изменённые файлы

- `src/i18n/index.js`, `preferences.js`, `translation.js`, `locales/{ru,en,kk}.json`: инициализация i18next, общий хук `useI18n`, словари, перевод текущих сообщений API и подписка на смену языка.
- `src/hooks/useTheme.js`: независимое хранилище настройки темы. Только контрол выбора темы подписан на его изменения; переключение не обновляет дерево Workflow через React context.
- `src/components/UI/LanguageMenu.jsx`, `src/components/Workspace/AppearanceSettings.jsx`: переиспользуемые настройки.
- `src/styles/themes.css`: централизованная палитра и семантические переменные `--bg-primary`, `--text-primary`, `--text-secondary`, `--surface`, `--border`, `--shadow`, `--action-bg`.
- `src/styles/preferences.css`: меню, карточки тем и оформление светлого Workspace.
- Существующие CSS в `src/styles` и компонентах: исходные цвета заменены ссылками на токены. Значения тёмной палитры сохранены. Анимации Frame Tracing, Neural Pulse и reduced motion сохранены.
- Страницы и компоненты Header, Hero, Footer, Pricing, Generator, VideoShowcase, UI и Workspace: тексты, подсказки, состояния, ошибки и подписи доступны через общий хук. Даты используют выбранную локаль.
- `index.html`, `src/main.jsx`, `src/App.jsx`: восстановление настроек до рендера и подключение системы.
- `package.json`, `package-lock.json`: i18next и react-i18next. `vite.config.js`: отдельные предварительно загружаемые чанки словарей и i18n.
- `tests/i18n.test.js`: полнота словарей, параметры переводов, динамические ошибки, казахские символы и недоступный localStorage.

Backend, Prisma, контракты API и логика списания кредитов не изменялись.

## Как работает тема

По умолчанию включена тёмная тема. Ключ `betelgeuse:theme` хранит `dark` или `light`. Атрибут `data-theme` устанавливается до загрузки React. Светлая палитра действует на `/workflow`, `/library`, `/billing`, `/trends`, включая модальные окна в portal. Главная сохраняет исходное оформление. Выбор действует и при прямом переходе на вложенную страницу.

CSS меняет цвета без пересоздания компонентов. Промпты, загруженные референсы, результаты и доска Pro остаются в существующих состояниях. Хранилище темы не зависит от данных доски. Настройки синхронизируются между вкладками; если браузер запрещает localStorage, переключение работает в текущей вкладке.

## Как работают переводы

Ключи словарей — исходные строки интерфейса. `useI18n()` возвращает `t`, `language`, `locale`, `setLanguage`. Переводы доступны синхронно до первого рендера, без загрузки словаря после показа страницы. По умолчанию используется русский язык; выбор сохраняется в `betelgeuse:language`.

Серверные подписи и ошибки сохраняются в состоянии в исходном виде и переводятся при отображении. Известные динамические сообщения сопоставляются с шаблонами `{{v0}}`. Неизвестные сообщения показываются без изменений. Пользовательские промпты, имена, email, имена файлов и технические названия моделей не переводятся. React экранирует текст; HTML из переводов не вставляется.

Пример:

```jsx
const { t } = useI18n();
<span>{t('Действует до {{v0}}', { v0: date })}</span>
```

Чтобы добавить язык:

1. Создать `src/i18n/locales/<code>.json` с теми же ключами и параметрами, что в `ru.json`.
2. Добавить код и название в `src/i18n/preferences.js`.
3. Импортировать словарь и зарегистрировать его в `resources` в `src/i18n/index.js`, добавить локаль дат в `useI18n`.
4. Добавить код в начальный список языков в `index.html` и в проверку словарей `tests/i18n.test.js`.
5. Запустить `npm test` и `npm run build`, проверить длинные подписи на мобильном экране.

## Проверки и ограничения

- `npm test`: 23 проверки, включая существующие проверки CSRF, API, конфигурации Vercel, доски и параметров моделей.
- `npm run build`: успешная production-сборка. i18n и словари вынесены в отдельные чанки; основной чанк меньше 500 kB.
- `../artifacts/theme-i18n/audit.mjs`: нет русских JSX-текстов вне перевода и отсутствующих буквальных ключей.
- `../artifacts/theme-i18n/browser-qa.mjs`: desktop 1440 px, mobile 390/320 px, три языка, обе темы, меню, модальные окна, сохранение настроек и доски после перезагрузки, сохранность пользовательских данных, авторизация и отправка генерации с референсом через перехваченный API. Снимки и результат находятся в той же папке.

Проверки API в браузере используют фикстуры. Реальные платные генерации, OAuth у внешнего провайдера и деплой на Vercel не выполнялись. Сборка сообщает о существующей ссылке на отсутствующий `/images/hero.webp` в CSS; ресурс не добавлялся в рамках этой задачи. Новые серверные сообщения, которых нет в словарях, потребуется добавлять в три файла переводов.
